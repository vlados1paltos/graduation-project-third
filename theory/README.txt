ОТЧЁТ ПО ИТОГОВОМУ ПРОЕКТУ
«Лендинг с использованием Bootstrap»

Сначала установил зависимости через npm и запустил проект локально. Разобрался со структурой шаблона: исходная разметка находится в папке src/pug, стили — в src/scss, JavaScript — в src/js, а готовая сборка создаётся в папке dist.

Для своей JavaScript-логики я создал отдельный файл src/js/custom.js. 
Весь код поместил внутрь обработчика DOMContentLoaded, чтобы он запускался после загрузки элементов страницы.

В проекте я добавил три функциональности.

1. Кнопка возврата наверх

Кнопка появляется после прокрутки страницы более чем на 500 пикселей. При нажатии страница плавно возвращается в начало.

Для этого использовал:
- getElementById();
- addEventListener();
- событие scroll;
- событие click;
- classList;
- setAttribute() и removeAttribute();
- window.scroll() с плавной прокруткой.

Стили кнопки находятся в файле:
src/scss/components/_scroll-top-button.scss

2. Проверка формы подписки

Добавил собственную проверку email без использования сервиса SB Forms.

Форма:
- проверяет, введён ли email;
- проверяет правильность его формата;
- показывает сообщение об ошибке;
- активирует кнопку только при правильном email;
- после отправки показывает сообщение об успешном результате;
- не перезагружает страницу.

Для этого использовал события input и submit, методы checkValidity(), preventDefault(), textContent и работу с CSS-классами.

Стили формы находятся в файле:
src/scss/components/_email-validation.scss

3. Плавное появление секций

Добавил появление секций во время прокрутки страницы.

Для этого использовал IntersectionObserver. Когда секция попадает в видимую область экрана, JavaScript добавляет ей класс, после чего запускается CSS-анимация.

Стили находятся в файле:
src/scss/components/_section-reveal.scss

После внесения изменений я повторно собрал проект командой npm run build и проверил, что новые стили появились в итоговом файле dist/css/styles.css.

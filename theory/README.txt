ОТЧЁТ ПО ИТОГОВОМУ ПРОЕКТУ
«Лендинг с использованием Bootstrap»

1. Для выполнения проекта был использован готовый шаблон Start Bootstrap Grayscale.

2. Проект был установлен и запущен локально с помощью npm:
   - npm install
   - npm start

3. Была изучена структура проекта и готовой страницы:
   - исходная разметка находится в src/pug/index.pug;
   - стили находятся в src/scss;
   - JavaScript-файлы находятся в src/js;
   - итоговая сборка формируется в папке dist.

4. В проект был добавлен новый файл JavaScript:
   src/js/custom.js

5. В файле custom.js реализована кнопка возврата к началу страницы.

6. В JavaScript использованы:
   - addEventListener() для обработки прокрутки и нажатия;
   - событие scroll;
   - getElementById() для получения кнопки по идентификатору;
   - classList.add() и classList.remove() для изменения CSS-классов;
   - setAttribute() и removeAttribute() для изменения атрибута title;
   - window.scroll() для плавного возврата к началу страницы.

7. Для кнопки были добавлены отдельные SCSS-стили:
   src/scss/components/_scroll-top-button.scss

8. Кнопка:
   - скрыта в начале страницы;
   - появляется после прокрутки более чем на 500 пикселей;
   - плавно отображается с помощью CSS transition;
   - при нажатии плавно возвращает страницу наверх.

9. Новый файл custom.js подключён к странице после основного scripts.js.

10. Работа страницы проверена:
    - на десктопной ширине;
    - на мобильной ширине;
    - навигация и адаптив Bootstrap работают;
    - кнопка возврата наверх работает корректно.

Результат:
Создан и доработан адаптивный лендинг на Bootstrap с дополнительной функциональностью JavaScript и работой с DOM.
